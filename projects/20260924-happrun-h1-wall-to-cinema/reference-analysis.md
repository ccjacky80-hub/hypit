## Approved reusable grammar

1. Establish an ordinary, recognizable situation immediately.
2. Show a clear physical cause that motivates an impossible transformation.
3. Deliver the visual payoff early rather than explaining the product.
4. Hold the spectacle long enough to reward the viewer.
5. Return to the opening visual state so replay feels intentional.
